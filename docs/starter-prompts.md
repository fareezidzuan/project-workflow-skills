# Starter prompts

Things you can say to Claude once the skills are installed. You don't need to name the skill; Claude picks it from what you say. Swap the details in brackets for your own.

## Start a project
- "Start a new client project for [Kopi House]. It's branding and social posts, no code."
- "Set up a project folder for [the Q1 campaign] in my Google Drive."
- "Show me what you'd create for a new project, but don't create anything yet." (a dry run)
- "I'm new to GitHub. Set this up the simplest way."

## Meetings
- "Turn my last Granola call into meeting notes."
- "Here are my notes from today's client call: [paste]. Make them into a meeting note."
- "Summarise the comments on this Figma file: [link]."
- "Add the action items from that meeting to the project to-do list."

## Brand
- "Build a brand style profile from the files in 06-brand-assets."
- "Here's the client's brand guide PDF. What are their colours, fonts and rules?"
- "Check this Figma file against the brand profile: [link]."
- "Our blue is darker than that. Update the brand profile."

## Make designs
- "Make three Instagram post variants announcing [our opening on 1 March]."
- "Design a LinkedIn banner in our brand style."
- "Make an icon set for [delivery, pickup, menu, loyalty] that matches our brand."

## Keep things tidy
- "Health check my project."
- "Is anything in this project folder in the wrong place?"
- "Move these inbox meeting notes into the [Kopi House] project."

## When there's code
- "This project now has a website. Add Git."
- "Write the security docs." (once the app has logins, a database or outside services)
- "Explain what a commit is, using Figma as an example."

## Words you might see
Claude avoids technical terms when you're new to Git, but if one comes up, the [plain-language glossary](../skills/project-repo-setup/references/plain-language.md) explains each one with a Figma comparison.
