# House defaults (example)

Copy this file to `house-defaults.md` and fill in your own conventions. When `house-defaults.md` exists, the skill offers these values as the recommended options. Keep `house-defaults.md` out of anything you share publicly.

| Setting | Your value | Example |
|---|---|---|
| Meeting-note file name | | `YYMMDD-topic.md` |
| Session-log scheme | | daily `yyyy-mm-dd.md` |
| Repo location, solo work | | Google Drive (second backup) |
| Repo location, team work | | `~/Developer/` |
| Local repo parent folder | | `~/Developer/` |
| Cloud drive for inputs | | Google Drive |
| UI languages | | English + one other |
| Docs language | | English |
| Default docs placement | | Split (working docs inside, raw inputs outside) |
| Default source of truth | | Figma first |
| General file naming | | kebab-case, `YYYYMMDD` dates, `v01` versions |
